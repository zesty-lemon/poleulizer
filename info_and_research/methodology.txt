This file is a step by step running method for this project.

1) Download images from annotations file
   See scripts/download_street_images.py — drop XMLs in
   data/route_annotations/new_routes/, run the script, fully-downloaded
   batches move to data/route_annotations/onboarded_routes/.

2) Build the pole catalog by geohashing the VAIL-labeled pole coords
   See scripts/build_pole_catalog.py — reads every onboarded XML, geohashes
   each rigid.type=2 annotation's <gps>, dedups by cell, writes
   data/pole_catalog/poles.parquet. Every pole gets a stable
   geohash:<9 chars> ID derived entirely from the VAIL labels — no
   state utility database lookup in the critical path. The earlier
   GMP/VEC/WEC fetcher and the PoleCatalog query class are parked in
   temp_junk/ and can be reintroduced as a separate promotion pass when
   the project needs canonical state IDs.
